# V26.11 前端与阶段工作台

本批实现：OperationGraph 节点顺序导航、单步骤操作视图、步骤内附件及提交、独立历史记录、版本绑定、命令幂等、独立步骤验收/退回/补交、任务提交前步骤 Head 校验、内容哈希静态资源、Head/ETag 步骤读取，以及旧提交路由复用当前工作台。

业务权威来自任务入池时保存的 OperationGraph。记录保存不代表执行授权或系统评测通过；已提交和验收通过不能混用。旧版本记录保持可读，不能自动完成新版本步骤。附件为不执行的下载内容，最多 5 个、合计 2 MB，记录及附件哈希均验证。

默认页面收起诊断、证据和评测说明，当前步骤直接填写与上传。全局样式统一间距、卡片、状态层级；移动端顶部步骤可横向切换。任务总提交在当前页面完成，复用已有生命周期站点，不创建第二套任务状态机。

缓存：静态资源及懒加载页面使用文件 SHA256；任务读模型升级命名空间；当前步骤 Head 每次重新校验，304 复用同任务缓存。步骤内容和历史记录自带内容哈希。步骤草稿在切换时保留于内存，不承诺关闭浏览器后仍保存未提交附件。

评测：计算器绑定受支持的公式、版本及输入字段，重新计算合同哈希不能使公式与计算行为分离；缺少预期值不影响其他可计算指标。

验收由 Python 步骤/版本/附件/幂等测试与 Playwright 手机交互截图组成。该批仍需进一步完善全站经营、知识页布局、企业预设采纳差异和同任务贯通测试，不能把当前改动描述为整个 V26.11 全量完成。

后续加固：任务总提交将当前步骤快照写入既有证据 formFields，哈希损坏阻止提交；历史 Head/步骤内容通过任务范围内的不可变地址读取，相同内容在不同任务中分别保留。附件下载同时校验记录与文件。浏览器验收覆盖上传、退回、补交、通过以及移动端溢出检查。
